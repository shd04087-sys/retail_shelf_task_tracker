# AGENTS.md

## Working Rules

- Read `SPEC.md`, `TASKS.md`, and `TEST-CHECKLIST.md` before writing code.
- Do not start coding until you have written a short implementation plan.
- Build the smallest working version first.
- Do not add features that are not listed in `SPEC.md` unless asked.
- Do not use real company data.
- Prefer simple, readable code over complex architecture.
- After each major step, compare the result against `TEST-CHECKLIST.md`.
- If a requirement is unclear, make a reasonable assumption and record it in `README.md`.
- At the end, update `README.md` with:
  - project purpose
  - features
  - tech stack
  - how to run locally
  - how to test manually
  - limitations
  - future improvements

## Approved V1 Scope

The V1 app must allow a user to:

1. View fictional sample shelf/reset tasks.
2. Add a new task.
3. Edit an existing task.
4. Mark a task as complete.
5. Filter tasks by status.
6. View a simple dashboard summary.
7. Refresh the page without losing task data.

Do not add features beyond this scope unless the user explicitly asks.
